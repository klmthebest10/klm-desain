# KLM Desain

Editor desain grafis gratis di browser: template, teks, bentuk, 2.000 ikon, 1.600 stiker, latar generatif, hapus latar dengan AI (berjalan di perangkat), animasi, serta ekspor PNG, JPG, PDF, SVG, video, GIF, dan **PDF/TIFF CMYK untuk percetakan** (bleed & tanda potong).

Buka: https://klmthebest10.github.io/klm-desain/

## AI (Pollinations)
Fitur Desain ajaib, Foto AI, Ilustrasi AI, Teks AI, dan Tulis ajaib memakai akun Pollinations milik pengguna.
Buka tab **AI** lalu tekan **Masuk** (butuh App Key `pk_…` terdaftar dengan Redirect URI `https://klmthebest10.github.io/klm-desain/`) atau **Tempel key**.
Kunci hanya disimpan di browser pengguna, tidak pernah di repo ini.
